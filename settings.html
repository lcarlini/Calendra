Settings

Shared by every page. Everything here is stored only in this browser; nothing syncs between devices.

Appearance and display

TV mode makes text and clocks larger, strengthens focus outlines, hides secondary controls and lets the arrow keys move focus. It is never switched on automatically, whatever the screen size.

AI summaries

Optional. Summaries are generated only when you press a button on a news story, never automatically, and always show what they were based on. Pick a provider, or leave AI off.

A key kept in browser storage can be read by any script running on this page, and by browser extensions. Calendra does not encrypt it because that would not protect it from such code. Use a key with a low spending limit, and remove it when you are done. It is never exported and never logged.

This must be a running Ollama server. A web page cannot start programs on your computer. Browsers only allow the call if Ollama accepts this site's origin: start it with OLLAMA_ORIGINS=https://lcarlini.github.io (or the address you use). A page on https may also be blocked from calling a plain-http address by some browsers.

Your data

Calendar preferences, reminders, watchlists, saved deals and settings live in this browser (localStorage). Clearing site data or using another browser starts fresh. API keys are never included in an export.
